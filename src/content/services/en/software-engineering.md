## When this service is right for you

You have a product to launch, a process that has outgrown spreadsheets, or a system your customers or staff depend on every day. You need more than a website but less than a full in-house development team. Or you already have developers and need experienced help with a critical part of the work.

## How a project runs

Every project follows the same five steps: **understand, plan, build, launch, support**. Only the size of each step changes.

1. **Understand.** Workshops with the people who will use the system, a review of what exists today, and a first scope with the risks named.
2. **Plan.** A short written plan covering the data, the connections to other tools, hosting, security and the trade-offs we chose. You approve it before any code is written.
3. **Build.** Cycles of one to two weeks. Each one ends with a working version on a private test site that you can try yourself.
4. **Launch.** Automated tests and releases, monitoring and alerts, a launch checklist and a plan to roll back if something goes wrong.
5. **Support.** Maintenance, improvements and the next features, or a documented handover to your team.

## What "ready for real use" means to us

- **Monitored:** errors and downtime are detected and reported from the first release, so problems are noticed quickly.
- **Secure by default:** each person and service gets only the access they need, passwords and keys are kept out of the code, and software updates are applied on a schedule.
- **Fast:** we set speed targets for pages and features, and we measure them.
- **Accessible:** interfaces that work with a keyboard and a screen reader.
- **Documented:** clear instructions so that a new developer can install and run the project quickly.
